# AvtoMarket MVP
Prvi delujoči frontend prototip sodobnega slovenskega avtomobilskega marketplace-a.

## Vključeno
- responsive mobile-first dizajn
- iskalnik po znamki/modelu
- kartice vozil
- modal za objavo vozila
- pripravljeno za kasnejšo povezavo s Supabase

## Lokalni zagon
Odpri `index.html` v brskalniku ali zaženi preprost lokalni strežnik.
